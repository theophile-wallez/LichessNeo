# Browser logos

The logos on the site's install buttons, each leading to its browser's store:

- `chrome.svg`: Google Chrome's icon, from
  [Wikimedia Commons](<https://commons.wikimedia.org/wiki/File:Google_Chrome_icon_(February_2022).svg>).
  A trademark of Google LLC.
- `firefox.svg`: Firefox's logo, from
  [Mozilla's Protocol](https://www.mozilla.org/media/protocol/img/logos/firefox/browser/logo.svg),
  under the [MPL 2.0](https://www.mozilla.org/MPL/2.0/). A trademark of the Mozilla Foundation.

They name the stores the extension is in, as each brand's guidelines allow, and are drawn as
published.
